# কৃষিসখা (KrishiSakha)

**স্মার্ট কৃষির পথে আমরা আছি আপনার পাশে** · Your smart farming companion

AI Builders Congress · Domain 7: AgriSphere AI · Team 01

কৃষিসখা (প্রতিযোগিতার ডোমেইন: AgriSphere AI) হলো কৃষকদের জন্য একটি বাংলা ভাষার অ্যাপের ডেমো। একজন কৃষক একবার নিজের জেলা, ফসল, জমি ও মাটির তথ্য দিলে পাঁচটি চ্যালেঞ্জের সব সেবা তাঁর জন্য মিলিয়ে দেওয়া হয়।

> **নোট:** এটি একটি ডেমো প্রোটোটাইপ। দাম, আবহাওয়া, ক্রেতা, ফলন ও খরচের সংখ্যা সবই নমুনা তথ্য। রোগ শনাক্তের ফলাফলও নমুনা, আসল AI মডেল এখনো যুক্ত হয়নি। OTP সবসময় `1234`, কোনো এসএমএস যায় না।

## পাঁচটি চ্যালেঞ্জ

| চ্যালেঞ্জ | অ্যাপে যা আছে |
|---|---|
| **YieldMax** (ফলন ও লাভ) | জমি, মাটি ও মৌসুম অনুযায়ী আনুমানিক ফলন, খরচ, আয় ও লাভের হিসাব। বিভিন্ন ফসলের তুলনা |
| **Precision Farm** (সার ও সেচ) | মাটির ধরন অনুযায়ী সারের পরিমাণ ও খরচ, সেচের সংখ্যা ও বিরতি, জমির আর্দ্রতার মানচিত্র |
| **Climate Smart Farming** (আবহাওয়া) | জেলাভিত্তিক ৭ দিনের পূর্বাভাস, ফসলের ঝুঁকি, করণীয় সতর্কবার্তা |
| **Crop Guardian** (রোগ শনাক্ত) | পাতার ছবি থেকে রোগের নাম, কারণ, লক্ষণ, প্রতিকার ও ওষুধের পরামর্শ |
| **FarmMarket** (বাজার ও বিক্রি) | বাজারদর ও ১০ দিনের পূর্বাভাস, বিক্রির সেরা দিন, সরাসরি ক্রেতার কাছে ফসল তালিকাভুক্তি, দরদাম চ্যাট, পরিবহন খরচ |

এর সাথে আছে **বাজেট** পেজ (খরচ ও আয়ের পরিকল্পনা), সাইন-আপ ও লগইন, **সেটিংস** (ভাষা: বাংলা/English, লেখার আকার) এবং **সহায়তা ও মতামত** ফর্ম।

## আসল লগইন (Firebase)

`firebase-config.js`-এ Firebase প্রজেক্টের কনফিগ বসালে **মোবাইল নম্বর + পাসওয়ার্ড** অথবা **ইমেইল + পাসওয়ার্ড** দিয়ে আসল সাইন-আপ/লগইন চালু হয় (কৃষক নিজে বেছে নেন)। মোবাইল নম্বর এখনো এসএমএসে যাচাই হয় না (SMS OTP-তে Blaze প্ল্যান লাগে), আর মোবাইল অ্যাকাউন্টের পাসওয়ার্ড রিসেট ইমেইল অ্যাকাউন্টেই সম্ভব। ইমেইল অ্যাকাউন্টে: সার্ভারে অ্যাকাউন্ট, ইমেইল যাচাই লিংক, "পাসওয়ার্ড ভুলে গেছেন" ইমেইল, আর কৃষকের প্রোফাইল Firestore-এ সংরক্ষণ। কনফিগ ফাঁকা থাকলে অ্যাপ আগের মতো ডেমো মোডে (নকল OTP `1234`) চলে।

## সহায়তা ও মতামত (Firestore)

ব্যবহারকারীর মতামত `feedback` কালেকশনে জমা হয় (Firebase console → Firestore Database → Data-তে দেখা যায়)। এটি চালু করতে Firestore Database তৈরি করে Rules-এ এটি বসান:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
    match /feedback/{id} {
      allow create: if request.auth != null
        && request.resource.data.uid == request.auth.uid
        && request.resource.data.message is string
        && request.resource.data.message.size() <= 1000;
      allow read, update, delete: if false;
    }
  }
}
```

সরাসরি ইমেইল দেখাতে `firebase-config.js`-এ `contactEmail: "আপনার@ইমেইল"` যোগ করুন।

## চালানোর নিয়ম

কোনো ইনস্টলেশন লাগে না। `index.html` ফাইলটি যেকোনো ব্রাউজারে খুললেই হয়। এটি একটি সম্পূর্ণ স্বয়ংসম্পূর্ণ পেজ।

GitHub Pages চালু করতে: **Settings → Pages → Branch: `main` / root** দিন।

## সোর্স ও বিল্ড

`index.html` তৈরি হয় `source/` ফোল্ডার থেকে:

```
source/
├── orig.html      # মূল কাঠামো
├── parts/         # আলাদা অংশ (CSS, জেলা, ফসল, রোগ, ক্রেতা, লগইন ইত্যাদি)
└── build.py       # সব জুড়ে ../index.html বানায়
```

```bash
cd source
python3 build.py     # ../index.html আবার তৈরি করে
```
